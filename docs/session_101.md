2. **The backdrop-button center trap** — the clone drawer's "Close
   navigation menu" aria-label belongs to the FULL-VIEWPORT BACKDROP BUTTON
   (absolute inset-0), not a glyph X: the 288px panel renders ABOVE the
   backdrop, so the button's own center lands on the panel's nav labels and
   an actionability-checked automation correctly refuses. The working probe
   picks a backdrop point CLEAR of the panel (elementFromPoint names the
   backdrop there) and takes the REAL mouse path (move + down + up). The
   two hosts' close surfaces differ by DESIGN (the reference's X glyph at
   (228,26); the clone's labeled backdrop) — the standing "X closes" row
   asserts each host's own control.

3. **The eval-context tooling shape** — agent-browser's `eval` takes an
   expression, not an async script body (top-level await throws
   ReferenceError; async page-context probes wrap in an IIFE); each eval
   re-declares its own locals (the sandbox persists the page, not the
   lexical scope); and the real-mouse path at coordinates is `mouse move` +
   `mouse down` + `mouse up` (there is no `mouse click` subcommand).
